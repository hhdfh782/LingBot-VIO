# Public release checklist

- [x] No passwords, API keys, SSH commands, private hosts, or internal server paths.
- [x] Pre-acceptance architecture preview contains no weights, runnable entry points, environment specification, or reproducibility artifacts.
- [x] Third-party license texts and notices are included.
- [x] Checkpoints, datasets, logs, and caches are excluded from Git.
- [ ] Publish authorized checkpoint downloads and SHA-256 hashes.
- [ ] Publish training/inference entry points, data loaders, configurations, environment, evaluation scripts, exact result tables, trajectories, and figure scripts after acceptance.
- [ ] Add the final paper DOI/arXiv identifier after publication.
